# The Reading Room

A centered Astro blog built from the Rico UI Astro starter, with Retro Blue as its default theme and Orama-powered search adapted from ZeroIndex.

## Run locally

```sh
npm install
npm run dev
```

Open the local address printed by Astro. To create a production build, run `npm run build`.

## Make it yours

- Replace the starter sample articles in `src/content/post/` with your own MDX posts. Search indexes post titles, descriptions, tags, headings, and body text automatically at build time.
- Change the blog name and introduction in `src/pages/index.astro`, `src/pages/blog/index.astro`, and `src/components/sections/Footer.astro`.
- Set your public site address with `PUBLIC_SITE_URL` for the sitemap and RSS before publishing.
- The color themes are in `src/config/themes.js`. Retro Blue is the default; visitors can choose another theme or dark mode in the top navigation.
